- `npm run format:check` — passed.
- `npm test` — 28 simulation, save, and native-adapter tests passed.
- `npm run build` — strict TypeScript checking and production build passed.
- `npm run test:e2e` — 20 browser tests passed across desktop Chromium and a Chromium-emulated iPhone viewport, with additional 320×568, 430×932, and 844×390 layout checks.

## Native verification boundary

The desktop/mobile checks use Chromium, not real Android WebView or iOS Safari. Gradle 8.14.3 started with Java 21 and configured the Android project, but `:app:assembleDebug` stopped at **SDK location not found**. No APK or signed app bundle was produced. Android device/emulator execution, immersive system bars, native plugin behavior, and Google Play upload remain unverified until an Android SDK and device are available. See `docs/android.md` for the setup and release steps.
